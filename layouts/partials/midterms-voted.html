{{- /* Week eight's lines for one state, as they stand on Election Day. Takes (dict "state" STATE "copy" WEEK.card_copy), where STATE is an entry from data/midterms_voting.yml, and returns a list of (dict "kind" "lead"|"bullet" "line" TEXT): a "lead" starts a block, a "bullet" sits under the lead before it, and a **bold** opening is the line's label. Same-day registration where the state has it at all today, then how a mail ballot still out can get back. By mail is now too late in a state that wants it received, and a gamble where a postmark counts, so the line says so and points to a drop-off when there is one still open today. midterms-card-week2.html sets these on the "I voted!" cards, and midterms-voted-html.html sets them as HTML in the week's action box, so the card and the page always say the same thing. */ -}} {{- $s := .state -}} {{- $c := .copy -}} {{- $blocks := slice -}} {{- if $s.sdr_election_day -}} {{- $where := index ($c.sdr_where_states | default dict) $s.code | default $c.sdr_where -}} {{- $blocks = $blocks | append (dict "kind" "lead" "line" (replace (replace $c.sdr "{state}" $s.name) "{where}" $where)) -}} {{- end -}} {{- $inPerson := index ($c.in_person_states | default dict) $s.code -}} {{- if and (not $inPerson) (eq $s.return_in_person "Tue, Nov 3") -}} {{- $date := partial "midterms-card-date.html" $s.return_in_person -}} {{- with $s.return_in_person_time }}{{ $date = printf "%s at %s" $date . }}{{ end -}} {{- $inPerson = replace $c.in_person "{date}" $date -}} {{- end -}} {{- $date := partial "midterms-card-date.html" $s.return_mail -}} {{- with $s.return_mail_time }}{{ $date = printf "%s at %s" $date . }}{{ end -}} {{- $mail := cond (eq $s.return_mail_received false) "mail_postmarked" "mail_received" -}} {{- if not $inPerson }}{{ $mail = printf "%s_no_dropoff" $mail }}{{ end -}} {{- $where := "by mail" -}} {{- with $s.return_methods }}{{ $where = printf "%s, by mail" . }}{{ end -}} {{- $blocks = $blocks | append (dict "kind" "lead" "line" (replace $c.return "{methods}" $where)) -}} {{- $blocks = $blocks | append (dict "kind" "bullet" "line" (replace (index $c $mail) "{date}" $date)) -}} {{- with $inPerson -}} {{- $blocks = $blocks | append (dict "kind" "bullet" "line" .) -}} {{- end -}} {{- return $blocks -}}
