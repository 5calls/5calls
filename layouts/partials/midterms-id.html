{{- /* One state's voter ID rules for the week-three action box, as HTML. Takes (dict "state" STATE "part" "lede"|"body") and returns a string, the same contract as midterms-deck.html and midterms-voting.html: the lede sits beside the state tag, the body under it. Returning a string lets the page print the reader's state and the state switcher carry every other state's, drawn by the same code. The state comes from data/midterms_id.yml, generated by scripts/build-midterms-id.py. Every line is shown by asking whether its key is there, so a state the question does not apply to simply has no line. A fixed running order, under "In-person voting in ": what the state asks for at the polls always whether it has to be current where there is a rule whether one document is enough where a second is wanted the accepted IDs except the no-ID states a photocopy of an ID in a mail 7 states; no other mail rule envelope is a voter ID question Unlike weeks one and two this page does name specific documents, under "Acceptable IDs include:". That list is the longest and most perishable part of the source, so the button under it goes to the reader's own election office, which is where the authoritative version lives. Not here: what happens to a voter who turns up with nothing, and how long they have to fix it. Both are still in the data and on the share card; the running order above has no place for them. It reuses the .mt-vote block from week two, which is the same shape of content: a line, with a bold lead where one is wanted. */ -}} {{- $s := .state -}} {{- $out := "" -}} {{- if eq .part "lede" -}} {{- $out = printf `

In-person voting in %s

` $s.name -}} {{- else -}} {{- $lines := slice -}} {{- /* What the state asks for, then the rules that qualify it. */ -}} {{- $lines = $lines | append (dict "text" (printf "%s." $s.lede)) -}} {{- with $s.current }}{{ $lines = $lines | append (dict "text" .) }}{{ end -}} {{- with $s.more_than_one_form }}{{ $lines = $lines | append (dict "text" .) }}{{ end -}} {{- /* The accepted IDs, one document to a bullet, from VoteAmerica's own per-state lists -- the same ones voteamerica.org/voter-id-laws/ renders. Most states publish one list; Colorado, Utah and Wyoming publish a second for non-photo documents or an alternative pair, so each list keeps its own heading. Items are markdown: a few carry a link to the state board's own roster of approved student IDs. */ -}} {{- range $s.accepted_groups -}} {{- $bullets := "" -}} {{- range .items }}{{ $bullets = printf "%s
  • %s
    • " $bullets (markdownify .) }}{{ end -}} {{- $lines = $lines | append (dict "text" (printf "%s" .heading) "list" $bullets) -}} {{- end -}} {{- /* What the source hangs off a list rather than putting in it: the currency rule, a first-time-voter proviso, an alternative to showing ID at all. */ -}} {{- range $s.accepted_notes -}} {{- $lines = $lines | append (dict "text" (markdownify .)) -}} {{- end -}} {{- /* The one mail rule that belongs here: the seven states where a copy of an ID goes in the envelope. A signature is checked everywhere, and a witness, a notary or a number written on the envelope are printed on the envelope itself -- none of them has to be known in advance, and none of them is a voter ID question. Enclosing a copy is both. */ -}} {{- /* Set bold: it is the only line in the box that is not about the polling place, and the one thing a mail voter has to act on before they seal the envelope. */ -}} {{- with $s.mail -}} {{- $lines = $lines | append (dict "text" (printf "%s" .)) -}} {{- end -}} {{- /* The bullet list is a sibling of the paragraph, never inside it: a ul nested in a p is invalid, and the browser closes the p early and leaves a stray tag behind. Week two's card does the same. */ -}} {{- range $lines -}} {{- $list := "" -}} {{- with .list }}{{ $list = printf `
      %s
    ` . }}{{ end -}} {{- $out = printf `%s

    %s

    %s
    ` $out .text $list -}} {{- end -}} {{- $out = printf `
    %s
    ` $out -}} {{- end -}} {{- return $out -}}
